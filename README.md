# 🎓 教务管理系统 (EduManage-OA)

一个基于 **前后端分离** 架构的教务办公自动化系统。本项目旨在解决学校教务场景中繁琐的成绩录入、课程排布及学生档案维护工作，提供极致的批量处理体验。

---

## 🌟 核心功能预览

### 1. 智能成绩管理 (Grade Management)

* **多模式查询**：支持按“全班”或“个人”维度精准检索成绩。
* **批量录入 (Excel)**：集成 Alibaba EasyExcel，支持上传 Excel 自动解析并入库学生成绩。
* **安全批量删除**：支持同科目下的多人成绩一键清理，内置 DTO 数据一致性校验。
* **补考/权值管理**：自动识别补考状态，支持学分与课程性质（必修/选修）展示。

### 2. 课程编排系统 (Course Scheduling)

* **课表维护**：实现课程的增删改查，支持班级与课程的多对多关联映射。
* **灵活调度**：可针对特定课程动态增加或移除参与班级。

### 3. 学生档案中心 (Student Records)

* **档案同步**：支持单人或批量导入学生信息。
* **学籍查询**：快速获取指定班级的学生名单与学号信息。

## 🛠️ 技术架构

### 前端 (Frontend)

* **核心框架**：React 18
* **UI 组件库**：Ant Design 5.x（采用最新的样式令牌系统）
* **路由管理**：React Router v6（支持动态路由跳转）
* **网络请求**：Axios（封装统一的响应拦截与错误提示）

### 后端 (Backend)

* **核心框架**：Spring Boot 2.1.0.RELEASE
* **持久层**：MyBatis Plus 3.4.3 & Spring Data JPA
* **Excel 处理**：Alibaba EasyExcel 3.3.2
* **项目管理**：Maven 3.6+
* **数据库**：MySQL

---

## 📂 关键 API 契约说明

项目严格遵循 RESTful 规范，特别是针对复杂业务采用了特殊的交互设计：

* **多人成绩删除 (DELETE)**：
发送 JSON Body 以确保删除操作的业务上下文（学年、学期、课程）完全正确。
* **成绩/学生导入 (POST)**：
采用 `multipart/form-data` 传输文件，结合 `@RequestParam` 绑定业务字段，实现单接口多功能复用。

## 🚀 快速开始

### 后端部署

1. 确保本地已安装 **JDK 1.8**。
2. 修改 `application.yml` 中的数据库连接信息。
3. 运行 `mvn spring-boot:run`。

### 前端部署

1. 进入前端目录运行 `npm install`。
2. 在 `.env` 中配置 `VITE_API_BASE_URL` 指向后端地址。
3. 运行 `npm run dev` 开启开发服务器。
